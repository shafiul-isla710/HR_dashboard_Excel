# HR Analytics Dashboard – Excel Project

## Project Overview

This project focuses on analyzing HR data to understand employee information, workforce distribution, and employee movement within an organization.
I used Microsoft Excel to organize and analyze the raw HR data, create Pivot Tables, and build an interactive dashboard.

The analysis covers employee attrition, onboarding, transfers, department-wise distribution, gender diversity, employment types, employee grades, and employee experience.

## Tools & Techniques

Microsoft Excel
Data Cleaning and Preparation
Excel Formulas (IF, YEAR, DATEDIF)
Pivot Tables and Pivot Charts
GETPIVOTDATA
Interactive Dashboard and Slicers


The main goal of this project is to turn raw HR data into meaningful insights and create an interactive dashboard that helps understand workforce trends and supports better HR decision-making.
